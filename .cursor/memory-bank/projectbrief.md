# MafiaHub Framework Project Brief

## Overview
The MafiaHub Framework is an opinionated suite of tools and libraries designed to accelerate the development of multi-player modifications for AAA games. It provides a common foundation and interface with shared functionality and data across different modification projects. The framework is currently at version 2.3.1.

## Core Goals
- Provide a robust foundation for multi-player game modifications
- Ensure consistency across all modification projects
- Simplify development through shared components and libraries
- Support a variety of platforms (Windows, Linux, MacOS)

## Key Features
- **Networking**: Tools to synchronize data between players
- **ECS (Entity Component System)**: Robust framework for entity management and world streaming
- **Scripting**: Lua scripting layer for creating and managing game modes
- **Logging**: System for tracking actions and errors
- **GUI**: Interface creation using Ultralight and DearImGUI libraries
- **Sentry**: Error and exception reporting service integration
- **Externals**: Wrappers for various libraries and services
- **Integrations**: Server and client moddable setup
- **Utils**: Useful functions and classes throughout the framework

## Project Structure
- `/code/framework/src`: Core framework components
- `/code/projects`: Where multi-player modification projects are stored
- `/vendors`: Third-party libraries and dependencies
- `/builds`: Build outputs
- `/cmake`: CMake configuration files
- `/docs`: Documentation
